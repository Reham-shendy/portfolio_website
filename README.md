# Personal Portfolio

A responsive and dynamic personal portfolio website designed to showcase my frontend development projects, skills, and background. 

##  Live Demo


##  Features
* **Dynamic Content Generation:** Project cards are generated dynamically using a JavaScript array, making it easy to add or update projects without touching the HTML.
* **Fully Responsive Layout:** Built with Bootstrap 5 to ensure a seamless viewing experience across desktops, tablets, and mobile devices.
* **Custom UI Design:** Features a custom dark theme with sophisticated gold and teal accents, complete with smooth hover animations and transitions.
* **Skills Visualization:** Clean, vertical progress bars to visualize technical proficiencies.
* **Sticky Navigation:** Easy access to different sections of the page while scrolling.

##  Technologies Used
* **HTML5**
* **CSS3** (Custom variables and styling)
* **Bootstrap 5** (Grid system and layout utilities)
* **Vanilla JavaScript** (ES6+, DOM manipulation)
* **FontAwesome** (Icons)
